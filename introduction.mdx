## How it works

Colyseus follows an **authoritative server** model. The server holds the source of truth for all game state. Clients connect to *Rooms*, send messages, and receive state patches automatically.

```
Client → join/create Room → Server runs game logic → State patches broadcast → All clients in sync
```

1. **Define a Room** — extend the `Room` class, set your state, handle player messages.
2. **Start a Server** — call `defineServer()` and register your rooms.
3. **Connect from the client** — use the Colyseus SDK to join or create a room.

## Quick example

```typescript server/rooms/GameRoom.ts
import { Room, Client } from "@colyseus/core";
import { Schema, type } from "@colyseus/schema";

class GameState extends Schema {
  @type("number") score: number = 0;
}

export class GameRoom extends Room<{ state: GameState }> {
  state = new GameState();

  onCreate() {
    this.onMessage("increment", (client, message) => {
      this.state.score++;
    });
  }

  onJoin(client: Client) {
    console.log(`${client.sessionId} joined!`);
  }

  onLeave(client: Client) {
    console.log(`${client.sessionId} left.`);
  }
}
```

```typescript server/index.ts
import { defineServer, defineRoom } from "@colyseus/core";
import { GameRoom } from "./rooms/GameRoom";

const server = defineServer({
  rooms: {
    game: defineRoom(GameRoom),
  },
});

server.listen(2567).then(() => {
  console.log("Colyseus server is running on ws://localhost:2567");
});
```
