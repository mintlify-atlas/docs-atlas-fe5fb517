## Prerequisites

- [Node.js](https://nodejs.org/) >= 20
- npm, yarn, or pnpm

## Create a new project

<Steps>
  <Step title="Scaffold the project">
    Use the official create script to generate a ready-to-run Colyseus server:

    <CodeGroup>
      ```bash npm
      npm create colyseus-app@latest ./my-server
      ```

      ```bash yarn
      yarn create colyseus-app ./my-server
      ```

      ```bash pnpm
      pnpm create colyseus-app ./my-server
      ```
    </CodeGroup>

    The CLI will ask a few questions (project name, language, transport) and then generate the project.
  </Step>

  <Step title="Install dependencies and start the server">
    ```bash
    cd my-server
    npm install
    npm start
    ```

    The server starts on **http://localhost:2567** by default.
  </Step>
</Steps>

## Generated project structure

```
my-server/
├── src/
│   ├── app.config.ts   # Server entry point — rooms, routes, express
│   └── MyRoom.ts       # Your first Room definition
├── package.json
└── tsconfig.json
```

| File | Purpose |
|------|---------|
| `src/app.config.ts` | Configures the server: registers rooms, Express middleware, and custom routes |
| `src/MyRoom.ts` | Defines game state and room lifecycle hooks |

## Define a Room with state

A `Room` holds your game state and handles client connections. Here is the pattern generated by the scaffold:

```typescript src/MyRoom.ts
import { Room, type Client } from "@colyseus/core";
import { schema, type SchemaType, MapSchema } from "@colyseus/schema";

// 1. Define your state with @colyseus/schema
export const Player = schema({
  x: "number",
  y: "number",
});
export type Player = SchemaType<typeof Player>;

export const MyRoomState = schema({
  mapWidth: "number",
  mapHeight: "number",
  players: { map: Player },
});
export type MyRoomState = SchemaType<typeof MyRoomState>;

// 2. Extend Room and attach the state type
export class MyRoom extends Room<{ state: MyRoomState }> {
  // Instantiate the state — Colyseus detects it automatically
  state = new MyRoomState();

  onCreate(options: any) {
    this.state.mapWidth = 800;
    this.state.mapHeight = 600;

    // Register message handlers
    this.onMessage("move", (client, message: { x: number; y: number }) => {
      const player = this.state.players.get(client.sessionId)!;
      player.x = message.x;
      player.y = message.y;
    });
  }

  onJoin(client: Client, options: any) {
    const player = new Player();
    player.x = Math.random() * this.state.mapWidth;
    player.y = Math.random() * this.state.mapHeight;
    this.state.players.set(client.sessionId, player);
  }

  async onLeave(client: Client, code: number) {
    this.state.players.delete(client.sessionId);
  }

  onDispose() {
    console.log("room", this.roomId, "disposing...");
  }
}
```

## Register and start the server

The `app.config.ts` file wires your room into the server using `@colyseus/tools`:

```typescript src/app.config.ts
import config, { listen } from "@colyseus/tools";
import { defineRoom } from "@colyseus/core";
import { MyRoom } from "./MyRoom.js";

export const server = config({
  rooms: {
    // The key "my_room" is the public room name used by clients
    my_room: defineRoom(MyRoom),
  },
});

listen(server);
```

<Note>
  `defineRoom()` returns a `RegisteredHandler`. You can chain `.filterBy()` and
  `.sortBy()` on it to control matchmaking behavior.
</Note>

## Connect from the client

Install the TypeScript/JavaScript SDK:

```bash
npm install @colyseus/sdk
```

Then connect to the room:

```typescript client.ts
import { ColyseusSDK, getStateCallbacks } from "@colyseus/sdk";

const client = new ColyseusSDK("ws://localhost:2567");

async function main() {
  // Join or create a room named "my_room"
  const room = await client.joinOrCreate("my_room");

  console.log("joined room:", room.roomId);

  // Listen for state changes using reactive callbacks
  const $ = getStateCallbacks(room);
  $(room.state).players.onAdd((player, sessionId) => {
    console.log("player joined:", sessionId);
  });

  // Send a message to the server
  room.send("move", { x: 100, y: 200 });
}

main();
```

<Tip>
  Use `getStateCallbacks(room)` to subscribe to fine-grained state changes
  (additions, removals, property updates) without polling.
</Tip>
