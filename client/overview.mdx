The Colyseus Client SDK lets your game or application connect to a Colyseus server, join rooms, exchange messages, and receive real-time state updates. A single unified API is available across JavaScript/TypeScript and all major game engines.

## How it works

1. Create a `Client` pointed at your server endpoint.
2. Call a matchmaking method (`joinOrCreate`, `join`, `create`, `joinById`) to enter a room.
3. The returned `Room` object exposes callbacks for state changes, messages, errors, and disconnections.
4. Call `room.send()` to push messages to the server at any time.

```typescript
import { Client } from "@colyseus/sdk";

const client = new Client("ws://localhost:2567");

// Join or create a room named "game"
const room = await client.joinOrCreate("game");

// Listen for state changes
room.onStateChange((state) => {
  console.log("new state:", state);
});

// Send a message to the server
room.send("move", { direction: "up" });

// Listen for a specific message type from the server
room.onMessage("scored", (data) => {
  console.log("player scored:", data);
});
```

## Core concepts

**Client** — The entry point. Accepts a server URL or structured `EndpointSettings` object. Exposes matchmaking methods, an HTTP client (`client.http`), and an authentication module (`client.auth`).

**Room** — The object returned after successfully joining a room. Holds the synchronized `state`, and exposes `onStateChange`, `onMessage`, `onError`, and `onLeave` event callbacks.

**State synchronization** — The server sends the full state on first join, then binary-encoded delta patches on every subsequent change. The SDK applies these patches automatically; your `onStateChange` callback always receives the latest full state.

**Reconnection** — The SDK automatically attempts to reconnect after unexpected disconnections (network drops, server restarts). Use `room.reconnectionToken` with `client.reconnect()` for manual or cross-session reconnection.
